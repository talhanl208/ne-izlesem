Önce TMDB anahtarını ekleyelim

Film verileri TMDB'den geliyor ve kişisel kullanım için ücretsiz bir API anahtarı gerekiyor. Beş dakikalık iş:

  1. themoviedb.org üzerinde ücretsiz hesap aç.
  2. Profil, Ayarlar, API bölümünden geliştirici anahtarı iste (kişisel kullanım seç).
  3. “API Read Access Token” değerini kopyala (“API Key” de olur ama token daha güvenli).
  4. Proje klasöründeki .env dosyasına TMDB_API_KEY=buraya_yapistir satırını ekle.
  5. Uygulamayı yeniden başlat.
